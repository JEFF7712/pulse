# Pulse Companion (Flutter)

Mobile client for Pulse: server URL + companion token, latest digest, date browser, corrections (`POST /api/corrections`), and optional FCM (device token → `POST /api/device-token`, tap notification opens digest by `context_id`). Targets iOS first; Android scaffolding is included for later.

Setup and commands: see [../CONTRIBUTING.md](../CONTRIBUTING.md) (Companion app section).
